# Production Drive storage cutover to rclone

Approved: replace active Drive API file-storage transport with rclone, preserve all Drive objects, YourWiki document IDs/URLs/content/history/ACL. Inventory:7 live bindings,all mapped to actual Drive IDs,none unsent; ordinary docx/xlsx/pptx/md/canvas/drawio, no native Google objects. Existing OAuth, user identity and cloud permissions remain control-plane functions. Standard Google trash/restore and permission control calls are retained to preserve exact object restoration; file byte transport/catalogue/create/mount use rclone, not old Google source/discovery/export workers.
