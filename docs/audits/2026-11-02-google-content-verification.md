# Google content transport verification

Task3 internal transport checkpoint; Google source resolver and production cutover remain disabled. `GoogleContentHttp` is worker-only and borrows shared scoped OAuth without owning its close. It performs lazy fixed-origin GETs only: binary `files/{id}?alt=media`, or explicit native document→DOCX, spreadsheet→ODS, presentation→PPTX export. Metadata ownership/current root/kind/canDownload checks must precede use; metadata/version/ancestry must be verified again after full consumption before accepting any source. Transport alone is not a source commit capability.

Binary declared size must be a safe integer in0..4294967296, optional content-length must match it, and actual EOF must match exactly. Returned pieces are copied and at most64KiB; no full-body arrayBuffer/text/Blob or retained chunk list is used in production. Native exports have unknown actual byte length and a10MiB local upper budget; Google's documented10MB export limit can fail earlier. Native metadata.size is not substituted for exported size. Header/body budget overflow or an exportSizeLimitExceeded response gets static PROVIDER_EXPORT_LIMIT. This does not claim that the provider guarantees10MiB or that this API supports4GiB native exports. Larger export/LRO support remains unproven and separate.

At most two content streams are active per transport. Each IO wait has a30s default idle limit, and transfer lifetime is bounded by30min default (internal options bounded at30s idle/1h total). Empty read framing has at most65536 empty chunks. Caller authority is rechecked before/after token/HTTP/read/yield/EOF; trusted session/job exceptions retain identity. Raw HTTP/transport/body errors are static. A pre-body401 permits one matching-token invalidation and safe GET retry; a stream/body failure never repeats the content request. Redirects/partial responses/content encoding are refused;404 never implies deletion,403quota differs from permission denial. Requests do not enable abuse acknowledgement. Abort and close cancel bodies, including late ignored-abort responses. close explicitly drains raw generators paused at consumer yield, and the exposed iterator reports cancellation rather than false successful EOF after shutdown.
