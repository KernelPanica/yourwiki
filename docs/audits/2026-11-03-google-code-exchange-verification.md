Code/credential/verifier/redirect inputs are bounded and checked before IO. Requests have manual redirects, no credential/referrer forwarding, no automatic retry and no source-file bytes. The same lease is consumed once across transport instances in this process; the existing durable claimed consent prevents a new lease after restart. A failed/ambiguous exchange requires new explicit consent.

An offline refresh token, valid bearer access token, positive integral lifetime and actual full Drive scope are required before exposing anything.

Token lifetime begins before the request with a safety margin; slow exchange does not extend it. The return value is a frozen private checked token capability, not a serializable HTTP token DTO. Its credential reads recheck consent authority, expiry, caller cancellation and transport lifetime. Shutdown drains admitted work, aborts pending authority/HTTP/JSON waits and cancels late bodies even if an injected fetch ignores AbortSignal. Issued credentials are not persisted or made active before the next account/root verification and atomic publication stage.
