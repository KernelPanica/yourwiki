Official reference refresh: [Docs batchUpdate](https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/batchUpdate) and [Slides batchUpdate](https://developers.google.com/workspace/slides/api/reference/rest/v1/presentations/batchUpdate) expose requiredRevisionId. The new GoogleNativeWrite protocol pins it; it does not use the merging targetRevisionId. [Sheets batchUpdate](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/batchUpdate) documents atomic batches and collaboration effects, but its current request schema has no writeControl. This is not evidence for equivalent optimistic concurrency. [Docs get](https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/get) requires includeTabsContent for all tabs; treating the default first-tab response as a full document would lose content. Current [Drive v2 update](https://developers.google.com/workspace/drive/api/reference/rest/v2/files/update) also does not document an If-Match final-commit guarantee; no v2/v3/Sheets guarantee was invented from other Google products.
