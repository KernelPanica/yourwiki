# Проверка безопасности и приёмки — 10 октября 2026

Проверены серверные ACL, WOPI, сохранение, история, загрузки, внешняя синхронизация и основные браузерные сценарии. Это проверка реализации и развёрнутого сервиса, а не независимый пентест всех внешних провайдеров.

## Исправленные ошибки

- DOCX после Collabora оставался корректным, но просмотр Yourwiki падал на стандартном OOXML-выравнивании `start/end`. Импорт теперь понимает эти значения, включая направление текста. Оригинальные байты не переписываются при просмотре.
- Сохранение прав отправляло запрос на адрес с `[object HTMLInputElement]`: поле `name="action"` перекрывало свойство `form.action`. Общий обработчик читает HTML-атрибуты. Браузерный тест теперь проверяет адрес POST, ответ сервера и фактически сохранённые права через API.
- Heartbeat Collabora проверяет изменения оригинала каждые 30 секунд. Чистый редактор переоткрывается с новым WOPI ID; при локальных правках появляется конфликт, старое сохранение не заменяет оригинал, доступно скачивание текущей копии. Поздние отправленные байты остаются восстановимыми.
- Некорректная WOPI-блокировка не может заменить восстановительную копию другого редактора. Скачивание восстановления ограничено автором отправленных правок и администратором.
- Убраны дополнительные сохранения при уходе из редакторов документа/PDF. Обычное автосохранение остаётся; несохранённые правки вызывают предупреждение, конфликт рекомендует копирование или скачивание.
- Загрузка перетаскиванием показывает конкретную ошибку размера, а не общий текст формы. `/tmp` контейнера увеличен до 256 МиБ для параллельной обработки загрузок.
- GitHub больше не получает персональные grants на репозиторий из прав отдельных файлов: это могло раскрыть соседние файлы. Ранее управляемые grants отзываются с сохранением состояния повторной попытки.
- Обновлены уязвимые зависимости: `urllib3 2.8.0`, `pypdf 6.20.0`, исправлена транзитивная зависимость npm. Аудиты Python requirements и npm lockfile не обнаружили известных уязвимостей на дату проверки.

## Критерии приёмки

| Критерий | Результат и границы |
|---|---|
| Открыть оригинал | Используется ссылка исходного объекта провайдера. Персональные read/write grants реализованы для Google и OneDrive. Владелец оригинала и независимо выданные внешние разрешения сохраняют свои права. GitHub не поддерживает изоляцию доступа по файлам; Yourwiki не выдаёт доступ к репозиторию. |
| Визуальное редактирование и сохранение | Реальная Collabora проверена для DOCX, Markdown, XLSX, ODS и PPTX; ввод в DOCX сохранён через WOPI. Остальные редакторы сохраняют свои форматы. Полное тождество возможностей Google/Microsoft и перенос всех особенностей нативных Google Sheets через ODS не гарантируются. |
| Read/write | Каждый WOPI-запрос проверяет актуальные права; write включает read. Читателю нельзя сохранить файл. Реальная совместная сессия проверена с администратором, обычным редактором и читателем. Изменение ACL доступно администратору Yourwiki. |
| Размер загрузок | Проверены лимиты 1, 5 и 8 МиБ, превышение на один байт, HTML/JSON и отсутствие отвергнутого файла. Через настоящий Nginx проверена загрузка 61 МиБ при значении 0. Администратор задаёт любое неотрицательное целое число МиБ; 0 отключает ограничение байтов. В production сохранено прежнее значение 5 МиБ, фиксированные барьеры Nginx отключены. |
| Глобальная история | Администратор включает/выключает историю для всех файлов; старые локальные флаги не переопределяют тумблер. При отключении новые снимки не создаются, существующая история сохраняется. В production история оставлена выключенной. |
| Совместное редактирование | Collabora использует общую сессию и показывает курсор/имя другого редактора. Старые редакторы/API не могут одновременно писать поверх активной офисной сессии. Браузерные проверки подтвердили курсоры также в текстовом и табличном редакторах Yourwiki. |
| Устаревшее сохранение | Сервер возвращает конфликт и сохраняет отправленную офисную копию для восстановления. Heartbeat и UI проверены для чистого и изменённого редактора. Уход со страницы не инициирует дополнительное сохранение. |
| Просмотр документов/таблиц | Исправлена регрессия DOCX из Collabora; проверены загрузка офисных форматов, режим чтения, адаптивные настройки прав и тема. Проверка всех возможных офисных файлов и их точного визуального совпадения не заявляется. |
| Внешние изменения | Открытые редакторы проверяют оригинал heartbeat; чистое состояние обновляется, локальные правки сохраняются при конфликте. Проверено локальным адаптером и контрактными тестами. Live-проверка конкурентной записи во всех облачных сервисах не выполнена. |

## Оставшиеся ограничения

Yourwiki не может отнять права владельца облачного оригинала или запретить доступ, независимо выданный вне Yourwiki. Ошибка внешнего отзыва отражается как незавершённая синхронизация и требует повторной попытки. Контрактные тесты grants не заменяют live-проверку реальных облачных аккаунтов.

Fingerprint предотвращает обнаруженные конфликты, но у адаптера без атомарного conditional write остаётся окно между проверкой версии и записью при стороннем изменении. Не следует считать эту проверку гарантией атомарности всех внешних API.

HTTPS перенаправляет Nginx; Django `check --deploy` отдельно предупреждает о выключенных Django SSL redirect и HSTS. Автоматическая политика HSTS для домена не вводилась. Серверные секреты и подписанные WOPI URL не включены в этот отчёт.
