## Продолжение: структура таблиц (8 октября)

- `Collaboration.saved_structure` и миграция 0018 хранят последний подтверждённый порядок идентификаторов строк/колонок, без копирования содержимого оригинала. При сбое/конфликте baseline не продвигается; новый flush использует прежнюю структуру. Старые сессии без baseline требуют явного reload для неоднозначных структурных изменений.
- Google Sheets получает insertDimension/deleteDimension/moveDimension и разреженные updateCells одним batchUpdate. Существующие примечания и validation перемещаются вместе с измерениями; повторное сохранение после подтверждения не вставляет строки заново. Неизвестные объединения вне представленной области не сбрасываются.
- Размеры пустой сетки записываются стандартными средствами ODS и читаются без встроенных метаданных Yourwiki.
- События Univer проверены по установленной версии 0.25.1, включая `move-columns`. Native Undo/Redo использует исходные идентификаторы, привязанные к объектам истории Univer; Yourwiki Undo восстанавливает их из CRDT.
- Браузерные проверки фактического удаления строки и Undo через панель Yourwiki и Ctrl+Z прошли (2 сценария); отдельный просмотр/совместное редактирование таблицы также прошёл.
- Миграция 0018 подготовлена и проверена на тестовой БД; на рабочей БД не применялась. Live Google API не вызывался.

Контракт структурных операций: [официальная документация Google Sheets](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/request).
