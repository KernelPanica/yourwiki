# Yourwiki UI: Sleek

The shared interface follows `DESIGN.md` and `typeui-fundamentals`. Its implementation lives in `wiki/static/wiki/sleek.css`, loaded after the existing layout stylesheet. Editor-specific styles retain control of document pages, canvases and compact PDF toolbars.

- Locally hosted Inter variable font (100–900), with its OFL license; JetBrains Mono for source and small section labels.
- Primary brand blue `#3B82F6`, violet secondary `#8B5CF6`. Text links and filled buttons use deeper blue variants to meet normal-text contrast requirements.
- White surfaces and slate background in light mode; slate surfaces and near-white text in dark mode.
- Spacing tiers: 8, 16, 24, 32 and 48 px. Corners: 4 or 8 px. Headings followed by explanatory paragraphs use 32 px of separation.
- Buttons normally have a 48 px height; dense editor controls retain a 44 px target. Sidebar controls expand on touch devices.

Theme selection is available in the workspace menu and on public authentication pages. It persists in `localStorage` as `yourwiki-theme` and synchronizes between tabs. Theme initialization runs before rendering; button labels and `aria-pressed` are refreshed after DOM loading.

Shared buttons retain native default, hover, active, focus-visible and disabled states. Existing submission handlers own busy, success and error states. File-type selection uses `aria-checked`, and theme/fullscreen toggles use `aria-pressed`. Reduced-motion preferences disable decorative transitions.

Validation covers desktop/mobile layouts, long names and RU/EN/ES labels, both themes, keyboard focus, semantic palette contrast, theme persistence, sidebar menus and Collabora/PDF pane resizing. Screenshots are generated by the opt-in browser suite. Collabora's embedded interface and user-authored document colors are controlled separately from the Yourwiki theme.
