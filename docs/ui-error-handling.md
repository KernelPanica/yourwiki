# Обработка ошибок интерфейса

Общие механизмы применяются к семействам действий, включая кнопки, добавленные динамически. Ошибки не означают подтверждение сохранения: при разрыве соединения или некорректном ответе пользователь должен проверить результат перед повторной отправкой.

| Действия | Обработка |
| --- | --- |
| Создание, настройки файлов/папок, права, пользователи, группы, приглашения | Общий POST-обработчик сохраняет форму при отказе; блокирует повторную отправку до завершения; восстанавливает кнопки в `finally` |
| Загрузка и импорт | Та же обработка, выбранный файл остаётся в форме; ошибки полей загрузки возвращаются JSON и показываются у полей |
| Перетаскивание файлов и папок, загрузка нескольких файлов | Общая проверка HTTP-ответа и сети; статус показывает число уже загруженных файлов при частичном успехе |
| Экспорт и скачивание оригинала через Yourwiki | Ответ проверяется до скачивания; ошибка остаётся на текущей странице |
| Кнопки и списки редакторов, комментарии, предложения | Общие `button`, `select`, `api` перехватывают исключения; повторный клик по выполняющемуся действию игнорируется |
| PDF: сохранение, скачивание, аннотации | Ошибки сети, размера, ответа, конфликта и отзыва доступа сохраняют локальные правки; кнопки восстановления остаются доступны |
| Буфер обмена и локальный снимок | Отказ clipboard приводит к скачиванию снимка; исключения скачивания тоже показываются |
| WebSocket редакторов | Некорректный ответ вызывает безопасное переподключение; локальные изменения остаются в очереди |
| Остальные локальные переключатели, масштаб, полноэкранный режим | Необработанные синхронные и асинхронные исключения показывают общий alert; CSS-режим работает при отказе браузерного fullscreen |
| Draw.io внутри iframe | Исключения и отклонённые Promise передаются в панель ошибок Yourwiki |
| Загрузка изображения, скрипта, iframe | Ошибка ресурса показывает сообщение о недоступном предпросмотре или компоненте |
| Вход, регистрация, выход, подключение OAuth и операции mount | Нативная навигация сохраняет переходы и OAuth; сервер возвращает безопасную страницу ошибки. Ответ внешнего сайта обрабатывает сам провайдер |

`wiki/static/wiki/ui-errors.js` содержит общий обработчик: сеть и таймаут, статусы 401/403/404/409/413/429/503, повреждённый JSON, закрываемый alert и сохранение ввода. POST-ответы, которые возвращают результат на той же странице (например, AI summary или новое приглашение), показываются без повторной отправки запроса. Отправка формы автоматически не повторяется; существующие механизмы автосохранения редакторов и восстановления соединения сохраняют свои проверки конфликтов и неопределённого результата записи.

`guarded`, `AccessMiddleware.process_exception` и обработчик CSRF формируют безопасные HTML/JSON-ответы. Неожиданные ошибки пишутся в серверный журнал без тела запроса. Клиенту не выдаются traceback и внутренние подробности. Существующая политика ответов при отказе доступа сохранена.

Проверки: `tests/test_ui_errors.py`, `tests/browser/test_ui_error_actions.py`; регрессии создания файлов, DOCX и PDF проверяются существующими браузерными сценариями.
