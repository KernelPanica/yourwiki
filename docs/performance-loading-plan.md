# Быстродействие и индикаторы загрузки

Цель: уменьшить повторные SQL-запросы при построении проводника и показать загрузку при пользовательских действиях без мигания от heartbeat.

- Измерить рост запросов на вложенных папках; добавить регрессионные проверки прав и изменений ACL.
- Загружать граф папок и группы пользователя одним набором запросов; использовать его при проверках прав, без общего кэша разрешений между запросами.
- Добавить общий счётчик активных загрузок, доступный статус, индикаторы переходов, форм, редакторов и сетевых действий; освобождать состояние при ошибках и возврате браузером.
- Не показывать общую анимацию на автоматических проверках синхронизации. Учитывать уменьшение движения и темы.
- Проверить серверные тесты, браузерные состояния ошибок/параллельных запросов, сборку и рабочий сервер. Обновить только web, сохранив сессии Collabora.

## Результат проверки

- Регрессия исходного поведения: 17 файлов во вложенных папках давали 635 SQL-запросов; новый тест требует не более 8 и проходит.
- Число запросов страницы папки не растёт при добавлении 20 файлов.
- Полный серверный прогон: 549 passed, 10 skipped.
- JavaScript: 19 passed. Браузер: загрузка, персональные права, ошибки форм, Presence документов; проверка совместного редактирования таблиц прошла при отдельном повторном запуске (первый параллельный прогон не дождался обновления ячейки).
- Сборка frontend и Docker успешна. Обновляется только web; Collabora сохраняет процесс и сессии.
